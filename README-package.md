# GRIDLOCK Coach — Claude Code package

**GRIDLOCK System · powered by UPRA · Coach Edition**

This folder is what you open in **Claude Code**.

## What is exact

| File | What it is |
|---|---|
| `web/index.html` | Working app. Open this in Chrome. |
| `ios/GRIDLOCK-Coach/` | Real Swift source from the early Xcode snapshot |
| `docs/GRIDLOCK-OVERSKILL-SPEC.md` | Full product spec |
| `docs/GRIDLOCK-OVERSKILL-IMPORT.txt` | Overskill paste prompt (not code) |
| `CLAUDE.md` | Rules for Claude Code |

The Overskill `.txt` is **not** the app. It is the English spec you paste into Overskill if you also want that builder to generate a hosted copy.

## Open it

1. Unzip `GRIDLOCK-CLAUDE-CODE.zip`
2. Open the `gridlock-claude-code` folder in Claude Code
3. Double-click `web/index.html` to see the app
4. Tell Claude Code: *read CLAUDE.md and keep building from web/index.html*
