Coach support

Keep your place.
Get back to the point.

Start with the quick fixes below. Your season lives on the device where you entered it.

Save and restore a season

  1. Open More → Nexus in the app.
  2. Choose Save a copy and keep the downloaded file somewhere you can find again. If a download or share sheet does not appear, use Show it as text and save the complete text.
  3. On the other device, open Load a copy and select that file. Review the squad and contents before loading it.
  4. Use merge to combine the copy with the current season, or replacement only when you intend to replace the current data. Save the current season first.

A class code is not a cloud invitation. A class and its sign-in sheet live on the device that created them. Pass that device around for sign-ins, or deliberately move a saved copy. Another phone does not automatically receive the class.

Common questions

Do I need an account?

Playbook, scouting, tally and participant sign-in can be used without a cloud account. Staff tools use an account created on this device. That login does not carry to another browser or phone.

Why is the app empty on another phone?

GRIDLOCK does not sync through a server. Use Save a copy on the original device and Load a copy on the destination device. Opening the app from a different browser or web address can also open a separate storage area.

What if my data disappeared?

Return to the original browser and address first. Clearing site data, private browsing sessions, resetting a device or uninstalling can remove local information. Installed native builds also keep a device-storage copy and try to restore it when available. In a browser, restore your own saved copy. There is no remote recovery service.

Did my message or league notice reach the team?

Messages and league notices are kept on this device. Saving a notice is not proof that anyone received it. Use a sharing option and finish sending in your chosen messaging app, or copy the text there yourself.

Can I use GRIDLOCK without signal?

The coaching tools calculate and save locally. The installed app works without signal. A browser needs to load the app first; offline availability depends on the browser keeping the installed or cached copy. Export a backup before relying on the device at an event.

How do I report a problem?

Note your device, browser or app version, the field and screen, what you did, and what happened. Save a backup before troubleshooting. Include a screenshot with personal information removed when useful.
